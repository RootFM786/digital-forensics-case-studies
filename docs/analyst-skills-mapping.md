# Analyst Skills Mapping

## How the Forensics Work Transfers to SOC / Security Analyst Roles

| Coursework Activity | Transferable Analyst Skill | SOC Example |
|---|---|---|
| Evidence log and chain of custody | Evidence accountability | Recording affected hosts, artefacts and handovers during a major incident |
| Contemporary notes | Investigation documentation | Maintaining a clear ticket timeline and analyst rationale |
| Identifying multiple evidence sources | Log-source selection | Choosing firewall, DNS, proxy, authentication and endpoint telemetry for an alert |
| Correlating incident time with network records | Event correlation | Matching a phishing click time with proxy, DNS and EDR events |
| Write-blocking / forensic preservation | Preserve before modification | Capturing volatile or relevant evidence before containment |
| Hypothesis-driven investigation | Structured analysis | Testing whether an alert represents compromise or legitimate activity |
| Minimum necessary examination | Scope control | Avoiding unnecessary collection of unrelated user data |
| Requesting authority / escalation | Escalation judgement | Passing a case to senior IR, legal or management when scope exceeds analyst authority |
| Handover to forensic examiner | Incident handover | Producing actionable notes for Tier 2 / IR teams |

## Strongest Portfolio Takeaway

The strongest link to analyst work is not the legal theory. It is the **investigative discipline**:

1. identify the question
2. preserve evidence
3. gather the right telemetry
4. correlate independent sources
5. document what is confirmed and what is not
6. escalate with a clear evidential record

That process is directly applicable to alert triage, phishing investigation, endpoint incidents, insider-threat cases and broader incident response.
